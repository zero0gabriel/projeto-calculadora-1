# 🧮 Calculadora Kawaii em Streamlit

Uma calculadora interativa e fofa desenvolvida em Python com Streamlit.

## 🚀 Funcionalidades
- ➕ Operações básicas: soma, subtração, multiplicação e divisão
- 🎶 Música de fundo integrada
- 🖼️ Interface visual personalizada
- ✅ Resultado exibido via notificação (toast)

## 🛠️ Tecnologias
Python | Streamlit
