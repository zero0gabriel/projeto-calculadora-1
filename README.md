# 🧮 Calculadora Kawaii em Streamlit

Uma aplicação de calculadora interativa e fofa feita com Python e Streamlit, com direito a imagem e música de fundo!

## 🚀 Funcionalidades
- ➕ Operações básicas: soma, subtração, multiplicação e divisão
- 🎶 Música de fundo relaxante
- 🖼️ Interface personalizada
- ✅ Resultado exibido via notificação (toast)

## ✏️ Como Personalizar
- **Mudar Imagem:** Altera o link em `st.image("URL")`
- **Mudar Música:** Altera o link em `st.audio("URL")`
- **Lógica de Cálculo:** Os cálculos são feitos pelo módulo `calculadora.py`

## 🛠️ Tecnologias
Python | Streamlit
